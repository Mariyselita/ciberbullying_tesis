# 🧠 Procesamiento de Lenguaje Natural (PLN)

Este módulo contiene los scripts utilizados para procesar, analizar y transformar texto en lenguaje natural como parte del proyecto de análisis de publicaciones en redes sociales.

## 🧾 Descripción

El objetivo de esta etapa es aplicar técnicas de **Procesamiento de Lenguaje Natural (PLN)** sobre el dataset preprocesado para extraer características relevantes del texto, preparar los datos para modelos de aprendizaje automático para su posterior uso de clasificación, análisis de sentimientos y detección de ciberacoso.

## 🧰 Funcionalidades incluidas

- Normalización y limpieza de texto
- Tokenización
- Stopwords y lematización
- Representaciones vectoriales (TF-IDF, Word Embeddings)
- Análisis de sentimientos
- Clasificación supervisada y no supervisada
- Visualización (nube de palabras, frecuencias, etc.)
