# 📥 Obtención de Datos

Este módulo contiene los scripts y configuraciones necesarias para la descarga y preparación inicial de los datos utilizados en este proyecto.

## 📚 Descripción

El objetivo de esta sección es automatizar el proceso de recolección de datos desde diversas fuentes (APIs y datasets públicos), así como asegurar una estructura de almacenamiento clara y replicable.

Por motivos de privacidad no se incluyen los objetos JSON.
