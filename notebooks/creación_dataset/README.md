# 🛠️ Creación del Dataset

Este módulo contiene los procedimientos utilizados para construir el dataset final a partir de datos crudos. Incluye limpieza, transformación, validación y generación de centroides.

## 📚 Descripción

El objetivo es generar un conjunto de datos estructurado y listo para análisis o entrenamiento de modelos. El dataset se construye a partir de archivos descargados previamente en el módulo `obtencion_datos`, así como de otras fuentes complementarias.
